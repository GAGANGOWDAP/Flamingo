# MODERN MINIMALIST FLAMINGO-THEMED SYRUP WEBSITE

Build a modern, premium, minimalist and highly polished company website for a syrup/product-based company.

The website must strongly focus on **UI/UX, visual hierarchy, smooth animations, whitespace, typography and premium presentation**.

## 1. IMPORTANT DESIGN DIRECTION

The main visual inspiration should be:

**Flamingo bird + artistic/minimalist aesthetic + premium syrup brand**

Primary brand color:

`#FFEAF3`

Use this as the main soft pink foundation, but do NOT make the entire website pink.

Create a sophisticated palette around it:

* Primary: `#FFEAF3`
* Deep pink/rose accent: use sparingly
* Soft white: `#FFFFFF`
* Off-white: `#FFF9FB`
* Dark text: `#242124`
* Muted text: `#777277`
* Very light pink borders: derived from the primary color

The website should feel:

* Elegant
* Fresh
* Premium
* Artistic
* Minimal
* Modern
* Soft
* Clean
* Professional
* Refreshing

Avoid:

* Overly colorful UI
* Heavy gradients
* Excessive shadows
* Clutter
* Too many animations
* Generic corporate templates
* Excessive rounded cards
* Excessive glassmorphism
* Unnecessary decorative elements

The flamingo concept should be incorporated subtly through shapes, curves, typography, decorative elements and visual composition rather than making the entire website look like a cartoon.

# 20. VERY IMPORTANT — LOW CREDIT / EASY EDIT ARCHITECTURE

I want to minimize Replit AI credits when making future changes.

Therefore:

### DO NOT hard-code product information inside JSX.

Create:

`src/data/products.js`

Store all product information there.

Example structure:

```js
export const products = [
  {
    id: "product-1",
    name: "Product Name",
    category: "Category",
    description: "Description",
    ingredients: [],
    sizes: [],
    details: []
  }
];
```

Populate this using the attached PDF.

This means future product changes can be made by editing ONE data file.
